# Prompt

## PrompTemplate

PrompTemplate is provided by Langchain, to generate templates of prompt. The templates have following properties

1. Reuseable
2. Langchain compatible - you can use it with chains
3. Validation - can validate the template that it contains all the require fields or not

## Messages

1. _System Message_ - system level message or system instructions
2. _Human Message_ - message by user
3. _AI Message_ - message or response by the AI/LLM
